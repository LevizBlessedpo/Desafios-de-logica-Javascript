# 🧩 Laboratório de Lógica de Programação & Algoritmos (JavaScript)

Repositório dedicado ao estudo, consolidação e resolução contínua de desafios de lógica de programação, manipulação de dados e algoritmos utilizando JavaScript.

---

## 📌 Metodologia e Filosofia de Estudo
- **Autonomia First:** Aplicação da regra dos 15 minutos para resolução de problemas antes de recorrer a documentações ou fóruns.
- **Hands-on & Bare Metal:** Implementação manual de laços, condicionais e estruturas sem dependência excessiva de métodos prontos/abstrações.
- **Ambiente Mobile Native:** Todo o ambiente de desenvolvimento, controle de versão e execução dos scripts é mantido de forma autônoma via celular.

---

## 🛠️ Tecnologias e Ferramentas
- **Linguagem:** JavaScript (Node.js / ES6+)
- **Editor de Código:** Acode IDE
- **Terminal CLI:** Termux (Linux environment)
- **Controle de Versão:** Git & GitHub
