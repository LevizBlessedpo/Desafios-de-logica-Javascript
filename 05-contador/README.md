# 🔢 Contador Numérico

Um projeto prático de manipulador de DOM desenvolvido para consolidar conceitos fundamentais do JavaScript Web.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização e layout.
- **JavaScript (ES6+):** Lógica de controle e manipulação do DOM (`getElementsByName`, eventos de clique).
- **Acode:** Ambiente de desenvolvimento (IDE mobile).

## 🎯 Funcionalidades

- Incrementar valor (+1) ao clicar no botão **Aumentar**.
- Decrementar valor (-1) ao clicar no botão **Diminuir**.
- Atualização dinâmica da interface em tempo real.

## 💡 Aprendizados

Durante o desenvolvimento deste projeto, explorei:
- Vínculo de scripts JS externos utilizando a tag `<script defer>`.
- Seleção e manipulação de elementos da tela via JavaScript.
- Resolução de problemas de escopo e retorno de elementos no DOM (`NodeList` vs elementos únicos).
